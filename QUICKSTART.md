# Quickstart

For the current Codex plugin, follow [Try it in one project](README.md#try-it-in-one-project). After setup, ask “What have we decided so far?” An empty journal is expected in a newly connected project.

When you return to agreed work, ask “What can I do next on the importer?” Signum looks up the contract and checks its current state. It can point you to the next step, ask which contract you mean, or explain what needs attention first. Looking up a contract leaves the project files and the owner's acceptance decision untouched.

For existing Claude commands or the earlier proof gate, use the [first-generation quickstart](archive/v1/QUICKSTART.md) with its matching revision.
