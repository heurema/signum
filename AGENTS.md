# Working on Signum

The active Codex packages live in `plugins/signum` and `plugins/signum-rust`. Their public marketplace is `.agents/plugins/marketplace.json`. Keep project activation explicit. Read the current journal schema and preserve existing records when changing a workflow.

Run `python3 -B -m unittest discover -s tests` at the repository root. Use temporary project directories for examples and tests. Keep personal project journals, transcripts and check reports out of contributions.

`archive/v1` is the public first-generation tree captured at the v2 transition. Keep historical files together there. Current installation and CI use the root checkout.
