# Security

Please report suspected security issues privately through the contact route on [skill7.dev](https://skill7.dev). Include the affected revision, the operation and its impact. Use synthetic evidence and keep project journals and credentials out of public issues.

The active plugin assumes that the owner controls the checkout and its local journal. People with write access can edit the records. A contract checks the persistent changes in a working copy. Verification commands run with the caller's OS permissions and may have side effects beyond the copy. Inspect commands and run them in an appropriate environment. Model suggestions and the results of checks still require the owner's judgment.

For the earlier generation, see its [security policy](archive/v1/SECURITY.md).
